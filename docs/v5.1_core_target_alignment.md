## 推理与评价路径

部署路径：合法影像 → A/U预测 → 原网格恢复 → 冻结接受/阈值规则 → 组织状态S及实例/核心R → 输出验证 → 私有保存。

评价路径：独立同例A/U + 完整复核/可见范围 → 冻结StateReference与核心关系参照 → 固定分母指标 → 每患者统计 → 按模式和任务判定。

两条路径分开。复核图、可见性真值或GT组织身份不得输入部署路径。S是显式交付与评价对象，不强制增加预测头。

## 必须在后续实施中通过的反例

- joint缺tissue_state_map、grid/scope/checkpoint不一致必须拒绝；module不能冒充joint。
- U阳性而A不确定：U和实例保持，S不可评价并标原因，不判正常。
- 所有U阴性但某个目标类未被接受：不能给目标阴性；已有已接受阳性不因另一类拒判被抹去。
- U正确但组织身份错误：可保留U成绩，组织身份—状态联合指标须体现失败。
- 增加拒判、预测组织范围外不能缩小参照分母；全拒判不能通过S。
- 只有near/nearest关系、只有A/U/R六格、或以3D-S填补2D-S，不能通过核心目标。
- 合格模型八格通过但H1无额外收益，可以核心能力成立而H1不支持；H2完成不能替代缺失同例S/R。

上述是待执行测试规范，不是本次运行通过的测试。真实标注、审批、阈值、资源和锁定评价仍按各自门槛执行。
