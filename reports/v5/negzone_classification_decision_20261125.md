## 1. 术语

- **所见**：模型给每个体素输出一个病变类别的概率。超过冻结阈值的体素连成的一片算一个所见；不足 50 体素的片不计。
- **大片所见**：软骨病变类不少于 10000 体素的所见，半月板撕裂类不少于 1000 体素的所见。
- **大片阳性区**：2026-11-12 的诊断发现，原运行在几乎每次扫描上都把大块软骨整片标成阳性，与扫描里有没有病变无关；框在定位那一步因此丢失。本实验要压住的就是这种现象。

## 2. 结果表第一行："软骨病变的大片阳性区压住了吗"

开发集共 33 次膝扫描，比较的都是第 6000 步的检查点。

| | 原运行 | 分区负项 |
| --- | --- | --- |
| 有大片软骨所见的扫描（有病变框） | 22 / 23 | 0 / 23 |
| 有大片软骨所见的扫描（无病变框） | 10 / 10 | 0 / 10 |
| 软骨所见总数（33 次扫描合计） | 15756 | 36890 |
| 每次扫描最大一块所见的中位数 | 22562 体素 | 913 体素 |
| 软骨所见的中位大小 | 73 体素 | 93 体素 |
| 软骨中超过阈值的占比：病变框内 | 0.251 | 0.125 |
| 软骨中超过阈值的占比：所有框外 | 0.234 | 0.116 |

**事实**

1. 大块消失：33 次扫描都没有 1 万体素以上的软骨所见，每次扫描最大一块的中位数从约 2.3 万体素降到约 900 体素。
2. 响应变成碎片，而不是消失：软骨所见的数量约是原来的 2.3 倍；超过阈值的软骨面积约减半，剩下的部分分散成很多小块。
3. 减少幅度在框内和框外大致相同：框内从 0.251 降到 0.125，框外从 0.234 降到 0.116。框命中 31 / 53，同一扫描内随机换位的期望命中率是 0.630，p = 0.898，命中没有高于换位对照。

**解释**：所谓"压住了"，只在"不再有大块"这一层意义上成立。阳性面积虽然减半，但病变处和正常处减少得一样多，所以这一行本身不能算改善的证据。

**未检验的假设**：响应被"拆碎"，而不是被"压住"。上面的数字只描述现象，没有给出原因。

## 3. 需要研究者决定：最终归类

按预注册 §5，从"阳性 / 阴性 / 不确定"中选一个。预注册写明"最终归类由研究者判断"。

### 3.1 冻结条件与本次事实

| 归类 | 冻结条件 | 本次事实 | 是否符合 |
| --- | --- | --- | --- |
| 阳性 | 大片阳性区被压住，**并且**框命中高于换位对照，**并且**脑与膝组织没有实质变差 | 框命中 31 / 53，换位期望 0.630，p = 0.898；髌骨软骨 Dice 从 0.772 降到 0.573 | 不符合，有两条不满足 |
| 阴性 ① | 大片阳性区仍出现在绝大多数扫描上 | 软骨 0 / 33，半月板 33 / 33 | 只有半月板符合 |
| 阴性 ② | 大片阳性区消失，框内响应也消失或碎成不足 50 体素，**并且**排序没有检出、也不高于原运行 | 软骨碎片的中位大小是 93 体素，不是不足 50；半月板排序检出（0.669，区间 0.568–0.767，Holm p = 0.008；原运行 0.466） | 不符合 |
| 不确定 | 有一部分改善（例如大片阳性区减少，或检出排序证据），但框命中不高于换位对照；或其他任务明显变差 | 软骨大片阳性区消失，半月板检出排序证据；框命中不高于换位对照；髌骨 Dice 下降 | 两部分都符合 |

两类病变的情况不同。软骨更接近阴性：大块消失，没有排序证据（0.476，区间 0.357–0.591）。半月板的大块还在，但检出了排序证据。两类合起来看，只有"不确定"的条件能与全部事实对上。

### 3.2 各归类的后果（预注册中事先写明）

- **阳性**：之后才值得考虑正项的空间约束、修订负资格或更长的训练，每一项都另行请示。
- **阴性 ①**：假设不成立，负项按解剖分区不是大片响应的原因。
- **阴性 ②**：在这种监督下，模型分不开同一块组织上的框内与框外。下一步应转向监督的信息量（标注、专家复核、别的学习目标），不再调整损失的形式。
- **不确定**：预注册没有规定固定的下一步。结果报告第 8 节列了两项不需要重新训练的检查：
  - 读第 2000、4000 步的检查点，看半月板的排序证据是否稳定；
  - 查髌骨软骨 Dice 的下降集中在哪些扫描上。

不论归为哪一类，都不自动启动下一次训练，也不改 `scientific_conclusion`。

### 3.3 执行方建议

建议归为**不确定**，这是唯一与冻结条件完全对得上的一档。

研究者也可能认为半月板的排序证据只来自一次运行、一个种子，分量不够，从而按阴性处理。这样做时应在记录里写明理由，因为本次事实不完全符合阴性 ① 或 ② 的字面条件。
