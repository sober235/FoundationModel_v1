## 1. 目标（2026-11-10 修订，未变）

给模型一份 MRI 影像和它的扫描协议，模型找出病变，圈出大致位置，并说明"在某某结构上，疑似某某异常"。成果给医生看。对错的标准是医生在数据集里留下的标注。

- 一个模型（同一个检查点）处理两种协议：膝关节 qDESS（SKM-TEA）和脑 DWI + ADC（ISLES-2022）。
- 输出跟随医生的标注形式：
  - 膝：六块组织的轮廓，以及病变框，每个框带病变类别和所在组织组；
  - 脑：梗死轮廓，说明"疑似缺血性梗死"。
- 只做三维。与两个单独训练的基线并列对照，"不应明显变差"，不设数值界限，由研究者判断。

设计：`docs/superpowers/specs/2026-11-10-unified-lesion-finding-design.md`。计划：`docs/superpowers/plans/2026-11-10-unified-lesion-finding.md`。

## 4. 诊断（2026-11-12）：为什么找不到病变

对同一个检查点，不再训练，只评价：

- **不是过拟合。** 框命中率 train 0.226（24/106），dev 0.208（11/53），同样低。
- **失败在定位点这一步。** 每个框里都有响应，也都有连通块触及框。但 train 82 个、dev 42 个框的连通块太大，体素数中位数约 3.6 万和 3.2 万，只有约 5% 落在框内，定位点因此落在框外。
- **每次扫描都有大片阳性区。** train 86/86、dev 33/33 的扫描，都有不少于 1 万体素的"软骨病变"所见和不少于 1000 体素的"半月板撕裂"所见。train 里 18 次没有任何框的扫描（训练时全是负样本）也一样。
- **证据支持、未检验的解释：** 原训练目标里，负项对全部负体素取平均，被大量容易的负体素稀释。模型对整块组织都给出阳性，也能把框目标压得很低。

## 5. 负项短程试验（2026-11-12 至 11-13）

**改了什么：** 只改膝关节框监督的负项。每类在整个批次的可用负体素里，只取概率最高的 1%（`negative_topk_fraction=0.01`）求平均，其余不变。训练到第 6000 步受控停止，学习率仍按 30000 步的期限。对照是原运行同一步的检查点。

- 计划 sha256 `b7e9524156d61e8df3ab58c0f4e91ed429cd181ca5d914c0eb1ad3a2cc105c69`。与原计划只差研究者批准的四项。
- 试验运行第 6000 步的检查点 sha256 `972cfcbde182bfdfb806f5b2dee403f0d7bbce6ffee5ede0480dc4d4a8e406a3`。

**可比性：** 两次运行的初始化相同；6000 步里每步的监督体素计数（18000 项）和学习率一致。全局随机数状态不同，但训练没有用到它们。回放：监督体素计数 12000 项、框目标各项的计数 36000 项与训练日志全部一致。

**第 6000 步结果（原运行 → 试验运行）：**

| 项 | train（仅诊断） | development_val |
| --- | --- | --- |
| 膝关节所见 | 54750 → 0 | 20391 → 0 |
| 命中的框 | 67/106 → 0/106 | 28/53 → 0/53 |
| 有响应，但连通块都小于 50 体素的框 | 0 → 101 | 0 → 49 |
| 框内最大概率 ≥ 0.5 的框 | 106 → 101 | 53 → 49 |
| 框内最大概率 ≥ 0.9 的框 | 106 → 34 | 52 → 20 |
| 袋内前 10% 体素的平均概率（中位数） | 0.994 → 0.596 | 0.993 → 0.544 |
| 脑梗死 Dice | — | 0.698 → 0.681 |
| 脑每例误报数 | — | 1.579 → 4.026 |

- **大片阳性区没有了。** 119 次膝关节扫描上没有不少于 50 体素的连通块；达到阈值的体素降到原来的约 1.6%（软骨病变）与 5%（半月板撕裂）。
- **一条所见也没有。** 剩下的阳性是零碎小团，软骨病变约 95% 只有 1–9 个体素。框内响应减弱但没有消失，半月板撕裂保留得比软骨病变好。
- **原运行第 6000 步的命中率不能读作定位能力。** 它每次扫描约 620–640 条所见，偶然命中的水平没有测量。
- **脑与膝组织：** 各只有一次运行，分不清是这次改动造成的，还是运行之间的波动。膝组织 dev Dice 有 5 个低 0.003–0.045，1 个高 0.022。
- **按研究者给的两条读法，都不完全适用。** 能说的只有：评价规则不变时，这个设置在第 6000 步没有产生任何所见；它去掉了大片阳性区，留下较弱、零碎的框内响应。这不说明病变学不到，也不排除负项稀释是原运行大片阳性区的原因之一。

**预算：** 按本机计时相加 13.004 h，在 16 h 上限内，剩约 3.0 h，不够再做一次同样规模的试验。第一次对原运行的只评价因实例掩膜的内存上限停止，修正（`048b3bb`）后重跑；这是实现上的保护，评价规则没有改。

## 6. 执行方的读法

已确定的事实、证据支持的解释、仍待检验的假设，在试验报告 §9 里分列。要点：

- 已确定：难负项去掉了大片阳性区；没有所见，是因为剩下的阳性太零碎，不是框里完全没有响应。
- 证据支持（中）：目标函数的平衡明显偏向了负项。到第 6000 步，高响应负体素已经少于原运行训练完的第 30000 步，袋内响应却远弱于原运行同一步。
- 未测量：
  - 零碎是不是目标函数本身造成的：正项只要求每个袋最高的 10% 为阳性，零散的体素就能满足；
  - 继续训练会不会连成块；
  - 比例调大是否两头兼顾；
  - 框内阳性比例高于框外（约 1.4–2.1 倍）是否反映病变信号，因为没有置换对照；
  - 脑的变化是否来自膝的负项。

**问题 1：下一步做什么？**（试验报告 §10）

| 选择 | 做什么 | 检验什么 |
| --- | --- | --- |
| A 继续 | 同一设置训练到更多步（例如 12000），学习率期限仍是 30000 | 零散的响应会不会连成块 |
| B 只调一个因素（执行方建议） | `negative_topk_fraction` 由 0.01 调大（例如 0.05），其余与本次完全相同，6000 步，同样的对照与评价 | 较温和的难负项能否既压住大片阳性区，又让框内响应成块 |
| C 重新考虑监督或优化 | 例如让正项要求成块的响应 | 零碎是否来自正项的设计 |

- 执行方建议 B：一次只改一个值，结果可以与本次和原运行并列比较。C 改动大，建议等 B 的结果出来再定。
- 不建议改评价规则、阈值或体素数下限来"救回"所见。这次的失败点清楚，改规则只会掩盖它。

**问题 2（可与问题 1 一起定）：是否给只评价加"偶然命中水平"的对照？**

- 内容：例如把框在同类扫描之间置换，估计随机所见的命中率。这样"每次扫描几百条所见"时的命中率才能和偶然水平比较；框内外阳性比例也能有对照。
