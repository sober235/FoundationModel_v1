## 0. 名词

- **主分析框**：医生画的、进入主分析的病变框（软骨病变、半月板撕裂）。**忽略区**：医生画了、但不进入主分析的框，训练时既不算正也不算负。
- **宿主组织**：框所属的组织。**袋**：一个主分析框内的宿主组织体素。
- **正项**：每个袋里响应最高的 10% 体素的 −ln(概率) 的平均，再对袋平均。0.693 对应概率 0.5；越小表示袋里的响应越高。
- **负项（原运行）**：每个类别全部可用负体素的 −ln(1−概率) 的平均，再对有负体素的类别平均。
- **负项（试验运行）**：每个类别在整个批次的可用负体素里，只取概率最高的 1%（个数向上取整），对它们的 −ln(1−概率) 求平均，再对有负体素的类别平均。正项、两项的权重（各 1.0）、可用负体素的定义都不变。
- **全部负体素的平均**：不管计划取多少，按原运行的方式对全部可用负体素求的平均。试验运行里它只记录，不参与优化。
- **高响应负体素**：概率不低于该类别阈值 0.5 的可用负体素。**覆盖率**：被 1% 选中的高响应负体素 ÷ 全部高响应负体素。
- **连通块、所见**：模型判为阳性（概率 ≥ 0.5）、彼此相连的一团体素；不少于 50 个体素的连通块才作为一条所见报出。
- **定位点**：一条所见里最靠近其质心的那个体素。定位点落在同类主分析框内，这个框才算**命中**；命中且所见给出的组织与框的宿主组织相符，算**命中且所在组织正确**。
- **IoBB**：所见的外接框与医生框的交集占医生框的比例。
- **患者等权**：先算每名患者的比例再平均；**合并**：全部框放在一起算。分母都是全部主分析框，未命中的框计入分母。
- **大片阳性区**：原运行每次扫描都有的、几万体素的阳性连通块（见 `unified_diagnostics_20261112.md` §7–§8）。

## 1. 摘要

1. **两次运行可比。** 初始化相同；6000 步里每一步的监督体素计数（18000 项）与学习率一致；三个检查点的采样器、调度器、训练数据摘要相同。全局随机数状态不同，但训练没有用到它们（§5）。
2. **大片阳性区消失了。** 第 6000 步，试验运行在膝关节 119 次扫描上没有任何一个不少于 50 体素的连通块；原运行同一步每次扫描约 46 万个"软骨病变"阳性体素、约 620–640 条所见。达到阈值的体素总数降到原来的约 1.6%（软骨病变）与 5%（半月板撕裂）（§8.3）。
3. **因此没有任何所见，框级结果全部为 0。** train 106 个、dev 53 个主分析框，没有一个被命中。失败点：train 101 个、dev 49 个框"框内有达到阈值的响应，但连通块都小于体素数下限"，其余 5 个、4 个框（都是软骨病变）"框内没有达到阈值的响应"（§8.1）。
4. **袋内响应减弱了，但没有消失。** 框内最大概率不低于 0.5 的框：train 101/106、dev 49/53（原运行全部）；不低于 0.9 的：34/106、20/53（原运行 106/106、52/53）。袋内响应最高的 10% 体素，平均概率的中位数 0.596 与 0.544（原运行 0.994 与 0.993）。半月板撕裂的袋保留得比软骨病变好（§8.2）。
5. **剩下的阳性是零碎的小团。** 软骨病变的连通块约 95% 只有 1–9 个体素，两类的连通块最大也不到 50 个体素。同类主分析框内宿主组织的阳性比例约是所有框之外的 1.4–2.1 倍（原运行约 1.1 倍）；这只是描述，没有对照（§8.3、§9.3）。
6. **组织 Dice 与脑。** 膝关节六个组织的 dev Dice 有 5 个比原运行同一步低（相差 0.003–0.045），1 个高 0.022；脑 dev 的每例误报数 4.026 对 1.579，HD95 32.7 mm 对 19.1 mm。各只有一次运行，没有区间（§8.4、§8.5）。
7. **按研究者给的读法：** 大片阳性区消失了，所以"这次干预尚未解决问题"这一条不适用；袋内响应没有消失，所以"这个设置未能保留有用的阳性证据"这一条也不完全适用。不超出证据的说法是：**在不改评价规则的前提下，这个设置在第 6000 步没有产生任何所见；它去掉了大片阳性区，留下的是较弱、零碎的袋内响应。** 这不说明病变不可学，也不排除负项稀释是原运行大片阳性区的原因之一（§9）。
8. **建议（未执行，需研究者决定）：** 只调整一个因素——把负项的比例从 0.01 调大（例如 0.05），其余不变，再做一次同样设计的 6000 步试验。理由与另外两种选择见 §10。没有接着跑 30000 步。

## 4. 代码核对（不是实验结果）

### 4.1 合成数据上的验证

- 负项只取整个批次里最高的 ceil(比例·N) 个可用负体素，个数按计划写的十进制算（0.01·700 = 7，不是 8）。
- 可选的负体素只由负样本掩膜决定，不从袋重建。类别只在有负体素时参与平均。
- 比例为 1 时与原来的目标函数逐位相同；不写这一项时，被优化的负项与"全部负体素的平均"相同。
- 训练每一步记录的正项、负项、全部负体素的平均与各类的计数，就是目标函数加进去的那几项；回放和探针都调用同一个函数。
- 停止步：学习率仍按完整期限计算；停止步落在两个检查点之间时也写检查点；停下的运行可以续训到停止步，不能在它之后暂停；不合法的停止步在写任何文件之前被拒绝。
- 只评价：所选检查点按步数和哈希核对；不属于该运行的选择在读数据之前被拒绝；其他检查点保存的输出从不复用；最终检查点重新推理与运行保存的输出一致。

### 4.3 一次失败的只评价与修正

- 第一次对原运行第 6000 步的只评价（2026-11-12 22:13 PST 启动）在膝关节 train 的第一次扫描上停止，失败码 `INSTANCE_LIMIT_EXCEEDED`。原因：这个检查点在一次扫描上给出 668–681 条所见，而实例掩膜的默认内存上限（16 GiB，每个实例一整卷的布尔掩膜）在 512×512×160 的网格上只容得下约 409 个实例。脑 dev 的 38 次扫描已完成。失败目录原样保留。
- 修正（`048b3bb`）：只评价可以显式指定这个上限，报告里写明；所在组织与定位点只在实例自己的外接框内计算（掩膜都在外接框内时与整卷计算结果相同，有测试）；数组哈希不再复制整个数组。阈值、体素数下限、定位点与匹配规则都没有改。
- 重跑用 256 GiB 的上限，在单独的工作树里运行，训练用的代码没有动。没有分配的掩膜页不占实际内存，本地按 800 个连通块测得峰值常驻内存 2.9 GiB。

### 5.2 随机数状态为什么不同

比较报告里"随机数状态"一栏在三个检查点都是"不同"。核对的结果：

- **事实**：每个检查点保存 Python `random`、torch CPU 与 CUDA 三个全局随机数发生器的状态。每次运行内部，这三个状态在第 2000、4000、6000 步完全相同，所以这一段训练里没有任何代码从它们取过随机数。CUDA 发生器的偏移量在两次运行里都是 0，即自设种子以来没有在 GPU 上取过随机数。
- **事实**：在 amax 的同一个解释器（torch 2.5.1+cu121）里，两个新开的进程起始的 torch 种子不同。两次运行的这三个状态不同，是各自进程起始状态不同。
- **事实**：代码里训练用到的随机性只有两处：模型初始化（在 `fork_rng` 里用计划的 `seeds.init` 设种子，结束后恢复全局状态）与裁块采样（每个成员自己的 PCG64 流，种子来自计划）。没有 dropout，没有数据增强，`anatobind/v41` 里没有别的 torch 或 Python 随机调用。
- **结论**：两次运行实际用到的随机性相同（初始化哈希相同；采样器状态相同；18000 项监督计数相同）。全局随机数状态的差别不影响训练。

### 5.3 训练代码的差别

原运行用 `17b4656`，试验运行用 `58a3c0e`。训练路径上的改动只有三处：膝 U 的目标函数改由 `box_mil_terms_v5` 计算（不写比例时与原来逐位相同，有测试）；停止步；每步记录损失各项。没有改动目标函数的任务，第 1 步损失两次运行逐位相同（§5.1）。

## 9. 证据评估

### 9.1 已确定的事实

- **F1** 两次运行的初始化、采样顺序与学习率相同；训练目标只在膝 U 的负项上不同（§5）。
- **F2** 试验运行第 6000 步：膝关节 119 次扫描上没有不少于 50 体素的连通块，所见 0 条；原运行同一步 train 54750 条、dev 20391 条（§8.1、§8.3）。
- **F3** 达到阈值的体素降到原运行同一步的约 1.6%（软骨病变）与 5%（半月板撕裂）；没有任何框的 18 次 train 扫描上，原运行 17/18 有不少于 1 万体素的软骨病变所见，试验运行 0/18（§8.3）。
- **F4** 框级结果全为 0。失败点：train 101/106、dev 49/53 是"有响应，但连通块都小于体素数下限"；其余 5 个、4 个软骨病变框框内没有达到阈值的响应（§8.1）。
- **F5** 袋内响应弱于原运行同一步，但没有消失：框内最大概率 ≥ 0.5 的框 101/106 与 49/53；袋内前 10% 体素的平均概率中位数 0.596 与 0.544（原运行 0.994 与 0.993）。半月板撕裂的袋保留得比软骨病变好（§8.2）。
- **F6** 试验运行的连通块全部小于 50 体素；软骨病变约 95% 只有 1–9 个体素（§8.3）。
- **F7** 宿主组织上的阳性比例，同类主分析框内与所有框之外之比：试验运行 2.1 与 1.4（软骨病变 train、dev）、1.8 与 1.9（半月板撕裂）；原运行 1.1、1.1、1.1、1.2。试验运行软骨病变忽略区内的比例（0.051、0.047）与框内相近（§8.3）。
- **F8** 训练日志：试验运行的正项从约 1.27（第 1–500 步平均）降到约 0.62（第 5501–6000 步），到最后仍在下降（§7.2）。固定批次上，正项在第 2000、4000、6000 步是 0.776、0.874、0.613，原运行同一步是 0.067、0.071、0.011（§7.1）。
- **F9** 固定批次上的高响应负体素（软骨病变）：试验运行 0.17%、0.10%、0.09%；原运行同一步 2.24%、1.11%、2.12%，原运行第 30000 步 0.43%。试验运行在三个时刻都覆盖了全部高响应负体素（§6、§7.1）。
- **F10** 膝关节组织 Dice（dev）：6 个组织里 5 个低于原运行同一步 0.003–0.045，1 个高 0.022。脑 dev：Dice 0.681 对 0.698，HD95 32.7 对 19.1 mm，每例误报数 4.026 对 1.579，检出率 0.519 对 0.497（§8.4、§8.5）。

### 9.2 证据支持的解释

- **E1 这个负项去掉了大片阳性区。** 两次运行只在这一项上不同（F1），大片阳性区在全部扫描上消失（F2、F3），训练中高响应负体素也一直远少于原运行（F9）。证据强；只有一次运行、一个种子。
- **E2 没有所见，是因为剩下的阳性太零碎，而不是框里完全没有响应。** 绝大多数框里仍有达到阈值的体素（F5），但它们的连通块都小于 50 体素（F4、F6）。证据强。
- **E3 目标函数的平衡明显偏向了负项。** 到第 6000 步，高响应负体素已经少于原运行训练完的第 30000 步（F9），而袋内响应远弱于原运行同一步（F5、F8）。证据中；"偏向"是相对原运行而言，最合适的平衡在哪里没有测量。
- **E4 原运行第 6000 步的命中率不能读作定位能力。** 它每次扫描有约 620–640 条所见（§8.1）。偶然命中的水平没有测量。

### 9.3 仍待检验的假设

- **H1 零碎是目标函数造成的。** 正项只要求每个袋里最高的 10% 体素为阳性，零散的体素就能满足；最难 1% 的负项对任何成片的框外阳性都罚得很重。两者合起来可能偏好零散的阳性。**没有测量**。
- **H2 同一设置再训练下去，袋内响应会连成不少于 50 体素的块。** 训练日志的正项到第 6000 步仍在下降（F8），但固定批次上的正项并不单调。**没有测量**。
- **H3 比例调大一些（例如 0.05），既能压住大片阳性区，又能让袋内响应成块。** **没有测量**。
- **H4 框内阳性比例高于框外（F7）反映了与病变有关的信号。** 不能确定：这是两个很小的比例之比，没有置换对照；软骨病变的忽略区与框内相近。
- **H5 脑的变化（F10）是膝 U 负项通过共享权重带来的。** 只有一次运行，不能与运行之间的波动区分。**没有测量**。
- **H6 病变能否用现有的框监督学到。** 这次试验不能回答：既不能说明不可学，也不能排除负项稀释是原运行大片阳性区的原因之一（E1 与稀释的解释一致，但一次运行不足以确认）。

### 9.4 按研究者给的读法

| 研究者给的情形 | 本次观察 | 是否适用 |
| --- | --- | --- |
| 大片阳性区与袋内响应都消失 → 只能说这个设置未能保留有用的阳性证据 | 大片阳性区消失；袋内响应减弱但仍在（F5） | 不完全适用 |
| 大片阳性区仍在 → 只能说这次干预尚未解决问题 | 大片阳性区消失（F2、F3） | 不适用 |

不超出证据的说法：在不改评价规则的前提下，这个设置在第 6000 步没有产生任何所见；它去掉了大片阳性区，留下较弱、零碎的袋内响应。
