## 4. 偶然水平对照：有效性评估

**跨患者置换不是有效的零假设，只作探索性报告。** 扫描之间没有配准，左右膝没有镜像；别人的框按体素下标搬到本次扫描里，可能落在组织之外。偶然水平因此被低估，低估多少不知道。一个只是跟着每次扫描的解剖走、并不认得病变的模型也会"显著"高于它。它的 p 值不用于声称学到了病变定位。

**改用的对照：同一次扫描内，沿所在组织挪动框。**

- 零假设：给定这次扫描的所见，主分析框可以等可能地落在同一次扫描里它的所在组织的任何位置。
- 做法：对每个主分析框，枚举同一体积内所有同样大小的摆放；所含所在组织（参照解剖）体素数与真实框处于同一个二倍区间 [2^k, 2^(k+1)) 的摆放算作可比。偶然命中概率是可比摆放里按不变的命中规则会被命中的比例。不抽随机数。
- 统计：各框的摆放在零假设下相互独立，命中框数服从泊松二项分布；p 是命中数不少于实际值的概率。
- 保持不变的：扫描本身及其解剖（有效空间区域）、病变类别、组织组、每个框的大小。不跨患者，所以不涉及配准与左右，也不引入患者之间的依赖。
- 为什么是精确的："可比"是等价关系，零假设下真实框在自己的等价类里均匀分布。
- 已做的验证（合成数据，`tests/v5/test_findings_chance.py`）：
  - 与逐个摆放按正式评分函数计数的结果完全一致；
  - 所见只在病变处时远高于偶然，所见铺满整块组织时等于偶然；
  - 零假设下模拟 400 次，p ≤ α 的比例不超过 α（α = 0.01、0.05、0.1、0.25）。
- 仍然不能说明的：病变在组织上的分布本来不均匀（例如承重区）。模型如果只学到"病变通常在哪里"，没有读到这一处病变的影像证据，也会高于这个偶然水平。所以"高于偶然"只表示"比同一组织上随机的位置好"，不等于证明了病变特异的定位。
- 参照解剖里不含所在组织体素的框没有可比的摆放，不计入，并报告个数。
- 这个对照还没有在真实数据上用过。第一次真实结果出来时，先报告可比摆放数与未计入的框数，再读 p 值。

二倍区间这个取法在看到任何真实结果之前定下，之后不改。

## 5. 三种结果的读法（不设数值界限）

| 结果 | 条件 |
| --- | --- |
| 阳性 | 框内响应恢复成所见；大片阳性区仍被压住；命中高于 §4 的组织内对照；脑与膝组织没有实质变差 |
| 阴性 | 大片阳性区重新出现；或响应仍然零碎，形不成有意义的所见 |
| 不确定 | 有改善，但不能确立病变特异的定位；或其他任务明显变差 |

- 不设数值界限；上面各项的数值与三个对照组并列给出，由研究者判断。
- 各只有一次运行、一个种子。脑与膝组织的变化分不清是这次改动还是运行之间的波动，报告里照此说明。
- 开发集上的改善不作为项目核心目标得到验证的依据。
