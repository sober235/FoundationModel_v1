## 3. 统计方案（一次修订，之后不改）

### 3.1 比较族

- **主要的探索性分析是 8 个比较**：development_val 上，四个检查点 × 两个病变类别（软骨病变、半月板撕裂）。主要量仍是 `topk_mean` 的百分位。
- train 上的结果只作诊断；两类合计只作描述。两者都不进入比较族，不校正，不判读，也不能代替 development_val 上的证据。
- 一个类别的结果不推广到另一个类别。

关于原方案的 `p1 ≤ 0.003`：它在原方案里写明是"0.05 除以 16 组"的 Bonferroni 界（0.05 ÷ 16 = 0.003125），16 组里包含 train。修订后的比较族只含 development_val 的 8 个比较，用 Holm 校正把族错误率控制在 0.05；Holm 不要求各比较相互独立（四个检查点读的是同一批扫描，本来就不独立）。

### 3.2 每个比较给出的数

| 量 | 定义 |
| --- | --- |
| 患者等权的平均百分位 | 先在患者内对他的各个框的百分位取平均，再对患者取平均 |
| 效应量 | 患者等权的平均百分位 − 0.5（零假设下的期望） |
| 95% 患者区间 | 对患者重抽样 10000 次（种子 20261114）的 2.5%–97.5%；**逐个比较给出，不是同时区间** |
| p（原始） | 患者等权的平均百分位高于 0.5 的单侧 p。零假设下每个框的百分位期望 0.5、方差为它自己的零假设方差，各框独立换位；患者等权平均的方差 = Σ_患者 [Σ_框 方差 ÷ 该患者框数²] ÷ 患者数²，用正态近似 |
| Holm p | 8 个比较的原始 p 按 Holm 逐步校正。某个比较不可判读时它没有 p，但仍占族里的一个位置（族的大小固定为 8，校正因此偏保守） |
| p（同患者相依） | 假设同一患者的各个框在零假设下一起移动（患者平均的方差取上界）得到的 p。**只作敏感性参考，不进入判读** |

原方案 §6.2 的其余各项（框数、可比摆放数的分布、框等权的平均百分位与它的 p1、最高十分位的 p2、单框 p ≤ 0.05 的框数）照旧给出，作次要的描述。

与原方案的差别：原方案的判读用的是框等权的 p1 加患者区间；修订后检验的统计量与报告的效应量是同一个（患者等权的平均百分位）。

### 3.3 判读

| 读法 | 条件 |
| --- | --- |
| **检出排序证据** | 效应量为正，**并且** 95% 患者区间的下限高于 0.5，**并且** Holm p ≤ 0.05 |
| **未检出排序证据** | 没有达到上面的条件。**这不是"证明了没有病变信息"** |
| **不可判读** | 支持不足、对照的假设不成立，或实现上的问题，使这个比较给不出有意义的结论（下表） |

"不可判读"在看到数据之前定下的具体条件（任何一条成立即是；这些界限是执行者把研究者给的三类情形落成可核对的条件，记在这里，之后不改）：

| 代号 | 条件 |
| --- | --- |
| `FEW_PATIENTS` | 该比较里有可用框的患者少于 10 名 |
| `MANY_BOXES_WITHOUT_BAG` | 该类别的主分析框里，参照解剖上框内没有宿主组织（因而没有袋）的超过 20% |
| `SMALL_POOLS` | 可用框里，可比摆放池小于 20 的超过一半（这样的池连单框 p ≤ 0.05 都达不到，对照说明不了什么） |
| `NO_NULL_VARIANCE` / `NO_INTERVAL` | 零假设方差为 0，或患者区间算不出来 |
| `JOB_NOT_COMPLETED` / `WEIGHTS_NOT_VERIFIED` | 该检查点的作业没有完成，或结束时权重未核对为未改动 |
| `PREFLIGHT_NOT_PASSED` | 该检查点的预检（§4）没有通过 |
| `SUPPORT_DIFFERS_BETWEEN_CHECKPOINTS` | 四个检查点读到的框数或摆放池不一致（按设计它们与检查点无关；不一致说明实现有问题，整个族都不可判读） |

- **0.5 是排序百分位在零假设下的期望，不是病变概率的阈值。** 这项审计不用任何概率阈值。
- 即使"检出排序证据"，说法也只是：**在所述的解剖对照下，框处的概率更高**。它不证明病变特异的定位；p 值不说明效应的大小、实用价值或机制。
- 四个检查点的读法不一致时，照实并列报告。原运行第 30000 步是历史上的诊断对照，它与第 6000 步的三个检查点**不是同等训练预算下的比较**。

### 3.4 零假设下期望为 0.5 的核对（含并列）

百分位 =（池中低于真实框的个数 + 相等个数的一半）÷ 池的大小，池里包含真实框自己。

- 池用全部可比摆放时：零假设下真实框是池中均匀的一个成员。对任意一组取值、任意的并列，各成员的中位秩之和是 n(n+1)/2，所以成员百分位的平均恰好是 [n(n+1)/2 − n/2] ÷ n² = 0.5。
- 池是"均匀、有放回地抽 1000 个，再加真实框"时：零假设下真实框本身也是等价类里均匀的一个摆放，这 1001 个是独立同分布的，因而可交换，真实框的百分位期望仍是 0.5。
- 测试 `test_the_percentile_of_a_pool_member_averages_one_half_whatever_the_ties`：全部相等、部分并列、两个值、单个值、随机并列、无并列的池，成员百分位的平均都等于 0.5（误差 1e-12 以内），方差等于池自己报告的零假设方差。

### 3.5 换位零假设与它的局限

零假设：给定这次扫描的概率图，每个主分析框等可能地落在它的等价类（同一次扫描、同样大小、同一组织组、所含宿主体素数在同一个二倍区间）里的任何一个摆放上，**各框相互独立**。

- 对患者重抽样处理的是患者之间的差异（一个患者多个框时的聚集）。它**不能**替"框可以怎样换位"这一假设作证；两件事分开陈述。
- 同一次扫描的几个框独立换位是假设。真实的框可能相邻、重叠，或集中在同一个间室；那时患者平均的零假设方差会被低估。"同患者相依"的 p 给出另一头的界，两者相差大时照实报告。
- 等价类只匹配扫描、组织组、框的大小与宿主体素数的量级，不匹配组织内的分区、软骨厚度或到关节面的距离。病变在组织上的分布本来不均匀：模型只学到"病变通常在哪一带"时，百分位也会高于 0.5。
- 与真实框部分重叠的摆放也在池里；对 `topk_mean`，含有同一处响应的摆放会与真实框并列，使它的百分位偏低（原方案 §7 已记）。
- 袋由参照解剖确定；参照解剖的误差同时进入真实框和它的可比摆放。
- 框是粗标注：框内的体素不都是病变，框外没有标注的体素不都是正常。这项审计评价的是与粗标注的关联。

## 4. 预检

冻结方案之后、正式作业之前，对四个检查点各做一次预检。

- **取哪些扫描事先定下**：train 里有主分析框的扫描，按样本标识排序后的前 2 个。不按结果挑选；只读 train。
- 预检**不报告任何排序结果**：摘要里没有百分位与 p 值，也不写出逐次扫描的行。不用预检的结果修改排序量或挑选病例。

| 检查 | 通过的条件 |
| --- | --- |
| 检查点的身份 | 文件 sha256 与登记的一致才加载；结束时权重哈希未变（入口自身的保护） |
| 输入归一化 | 每个通道有限；FOV 内的均值的绝对值 ≤ 0.001，标准差与 1 的差 ≤ 0.001（加载时按 FOV 内的均值与标准差归一化） |
| 恢复到原始网格 | 恢复后的概率与参照解剖形状一致；FOV 内被表示的体素占比 ≥ 0.99 |
| 概率的取值 | 有限，在 [0, 1] 内；解剖各类概率之和与 1 的偏差 ≤ 0.001；异常概率不是常数 |
| 解剖与标注对位 | 预测解剖（取概率最大的类别，不应用接受策略）对参照解剖，各组织 Dice 的平均在每次扫描上 ≥ 0.5 |
| 框与解剖对位 | 每个主分析框内都有宿主组织 |
| 资源 | GPU 显存与进程内存的峰值记录在案；速度由本机时钟与作业起止记账 |

Dice 的界取 0.5：已入库的 development_val 膝组织 Dice 在 0.65–0.82 之间（`negtopk05_pilot_20261113.md` §6.5），输入、网格或标注对不上时接近 0。这个界只用来发现对不上，不是性能指标。

预检未通过的检查点不启动正式作业，它的比较记为不可判读；先报告，不自行修改方案。

## 5. `census`（不需要模型）

按训练时的种子重抽裁块（固定、可重复的采样序列），逐步与训练日志核对。按病变类别分别报告：

- 可用负体素落在：该类别的宿主组织 / 其他已分割组织 / 其余有效体素；
- 来自哪一组扫描：有该类主分析框 / 只有其他的框（忽略区，或别的类别的主分析框）/ 没有任何框；
- 批次里出现该类袋的步数与占比（看正监督的出现频率）；
- **策略核对**：在 train 的全部扫描上，按框重新画出忽略区与该类主分析框，数其中的可用负体素。按已实现的策略两者都应为 0。

**可用负体素的计数 ≠ 被选中的难负样本的构成 ≠ 梯度的贡献。** `census` 只能说明第一项。负项取前 1% 或 5% 时被选中的是哪些体素取决于当时的权重；现有记录没有保存被选中体素的解剖构成，所以这一项与梯度的贡献在报告里都记为"**未测量**"。不由体素计数推断哪一类体素主导了负项的梯度，也不据此认定"按解剖分区的负样本"就是下一步。依赖预测或梯度的额外探测不在这次批准之内。

## 8. 审计结果与下一个实验的对应（替换原方案 §6.4）

排序审计与 `census` 用来**决定**方向，不是用来确认暂定的顺序。`modeling_options_20261114.md` 里"B 在前，A 其次，C 最后"只是当时按已有证据的暂定排序，**不作为既定的建模顺序**。

| 审计的结果 | 对下一个实验的含义 |
| --- | --- |
| development_val 上检出富集，但现有的所见仍然弥散或定位差 | 考虑 **A 空间约束的 MIL** 或 **C 直接的框级定位**；选其中改动较小、并且直接针对所观察到的定位失败的那一个 |
| `census` 显示负监督的构成失衡 | 考虑 **B 按解剖分区的负样本**，作为一个待检验的假设；不把它当作梯度行为的既定解释 |
| 只在 train 上有富集 | 先查泛化，再考虑后处理或更强的空间约束是否足够 |
| 两个划分上都没有可信的富集 | 先复核监督是否有效、几何是否对位、标注的信息量，再选别的学习目标。输出概率图里没有富集，不说明编码器里没有有用的信息 |
| 软骨病变与半月板撕裂的证据不同 | 按类别分别给建议，不强求一个解释覆盖两类 |

这些方向都不自动启动。

## 9. 收尾：一个可执行的建议

结果报告把排序结果与 `census` 合在一起，不再列一串开放的调查方向。它写明：

**观察到了什么 → 哪些解释有证据支持 → 什么还没有测量 → 推荐的唯一一个最小的下一步实验。**

对那一个实验写明：假设；唯一要改的一处；作对照的检查点或训练基线；申请的资源；沿用的端到端评价指标。最终的终点仍是膝关节病变的定位与所在组织变好，同时膝关节解剖与脑梗死的表现保持；排序的显著性不是终点。
