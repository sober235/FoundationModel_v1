# 监督资格与框级 MIL 目标的审计（2026-11-14）

本文件只含代码事实、已入库报告里的计数与判断；不含样本或患者 ID、路径或文件名。`scientific_conclusion: NOT_EVALUATED`；`core_target_validated` 保持 `null`。

**方法与范围。** 逐行阅读 `box_mil_terms_v5`、`box_bags_v5`、裁块采样、推理与评价链路的代码，并对照已入库的报告。这一轮没有在真实数据上运行任何东西，没有训练，没有新的数值。凡是需要新测量才能回答的，都标为"待测"，并指出由哪一项测量回答（`ranking_audit_prereg_20261114.md`）。

每一条结论归入三类之一：

- **实现缺陷**：代码与它的书面规定不符。
- **监督假设**：代码照规定做了，但规定本身包含一个关于标注或病变的假设。
- **待检验的假设**：关于"这是不是失败原因"的说法，现有证据不足以确定。

## 2. 实现是否与规定一致

**没有发现实现缺陷。** 依据：

- `box_bags_v5`（`anatobind/v41/engine/box_data_v5.py`）与它的模块说明、设计文档 §5.2 一致：主分析框成为袋（框内的宿主组织），框外为负，非主分析框是所有类别的忽略区。
- `box_mil_terms_v5`（`anatobind/v41/losses.py`）与它的说明一致：正项是每个袋最高 ⌈比例·n⌉ 个 logit 的 softplus(−logit) 平均，再对袋平均；负项是每个类别保留的负体素的 softplus(logit) 平均，再对有负体素的类别平均。负体素只由 `e_neg` 决定，不从袋反推。
- 训练、回放与探针读的是同一个函数。两次试验的回放把每一步的监督体素计数（各 12000 项）与框目标各项的计数（各 36000 项）同训练日志比较，不一致都是 0。
- 合成数据的单元测试覆盖了袋的构造、重叠、忽略区、负项比例与没有支持的情况。

这是静态审阅加上已有的核对，不是形式化的证明。下面几条是审阅中注意到的**设计性质**，都与规定一致，不是缺陷，但与后面的问题有关：

| 性质 | 位置 | 后果 |
| --- | --- | --- |
| 一个类别的负资格不排除**另一个类别**的主分析框 | `box_bags_v5`：只对本类别清除窗口 | 半月板撕裂的框内，软骨病变是负样本，反之亦然。两类的宿主组织不同，按规定如此 |
| 同类主分析框的**整个窗口**都不算负，包括框内不是宿主组织的体素 | 同上 | 框内非宿主体素上的响应既不被要求，也不被惩罚 |
| 两个同类的袋重叠时，体素归较小的袋 | 同上，按袋的大小排序后写入 | 较大的袋失去重叠部分，它的"最高 10%"在剩下的体素里取 |
| 正项对**袋**等权，负项对**类别**等权 | `box_mil_terms_v5` | 小袋与大袋权重相同；负项里每个类别各占一半，与该类别负体素的多少无关 |
| 负项的"最难的若干比例"在**整个批次**里合并后取 | 同上 | 一个批次两块裁块；难负体素可以全部来自其中一块 |
| 袋的"最高 10%"只在袋**落在裁块内**的部分里取 | 同上，袋与裁块相交后计算 | 见 §3.2 |
| 裁块中心有 0.5 的概率取在分割前景或袋的体素上，其余在有效视野内均匀取；扫描按轮次均匀轮换 | `box_positive_centers_v5`、`PatchSamplerV5` | 没有主分析框的扫描与有框的扫描被抽到的次数相同 |

## 3. 正项

### 3.1 正项是否允许弥散或零碎的响应

**代码事实。** 正项只读每个袋里 logit 最高的 10% 体素，要求它们高。对其余 90% 的体素没有任何要求；对这 10% 体素在空间上是否相连、是否集中，也没有任何项。袋是框内的全部宿主组织：train 上袋的体素数中位数 5590、最大 58877，主分析框中位数 35791、最大 852480。病变占袋的多大一部分没有标注。

因此下面三种输出都能把正项压到很低：

1. 响应集中在病变上；
2. 响应铺满整块组织（袋内全部体素都高）；
3. 袋内散布着互不相连的高响应体素，只要个数达到 10%。

正项区分不了这三种。能把 2 与 3 排除掉的只有负项，而负项管的是框外。

**已有的证据。**

- 原运行（负项取全部负体素平均）：袋内最高 10% 体素的平均概率中位数 0.986；袋内达到阈值的体素约 18%；同时每次扫描都有几万体素的大片阳性区。对应上面的第 2 种。
- 1% 试验：大片阳性区消失，膝关节所见为 0，响应是不足 50 体素的碎片。对应第 3 种。
- 5% 试验：所见恢复，大片阳性区也恢复。
- 三次运行只改了负项的取法，输出的形态就在第 2 种与第 3 种之间变化。

**归类。**

- "正项允许弥散与零碎的响应"：代码事实，是这个目标的结构性质。属于**监督假设**（假设负项足以把响应收拢到病变上），证据强。
- "这是定位失败的原因，加上空间约束就能修好"：**待检验的假设**。三次运行改的都是负项，没有一次单独改正项；并且还不知道概率里是否有与框相关的排序（排序审计回答）。如果没有，空间约束没有东西可以收拢。

### 3.2 裁块切开袋时

**代码事实。** 袋的"最高 10%"在袋落在裁块内的那一部分里取。裁块是 192×192×48；框可以比裁块大。

**已有的证据。** 回放给出袋落在裁块内的体素比例：软骨病变中位数 0.721，半月板撕裂 0.957。也就是说，软骨病变的袋有一半以上的出场是不完整的。

**归类。** **监督假设**：即使病变落在裁块之外的那一部分袋里，目标仍然要求裁块内的部分有高响应。这样的情形有多少，取决于病变在袋里的位置，没有标注，无法由现有数据算出。影响大小是**待检验的假设**。

## 4. 负资格是否会惩罚没有标注的病变

**代码事实。** 每个类别的负资格从"整个体积"开始，只去掉两种区域：所有非主分析框的窗口（对所有类别），以及本类别主分析框的窗口。再与有效视野相交。于是以下体素对一个类别都是负样本：

- 有该类主分析框的扫描上，框外的全部宿主组织；
- 没有该类主分析框的扫描上，忽略区之外的全部体素。train 的 86 次扫描里：软骨病变 49 次没有主分析框，半月板撕裂 60 次；其中 18 次没有任何框，22 次只有忽略区；
- 另一个类别的主分析框内；
- 骨、其他组织与没有分割标注的体素。

被排除在负样本之外的：1 级软骨病变、被排除的框和范围外类别的框（它们是忽略区）。这一点处理了"医生标了、但不进主分析"的病变。

**与 Proposal 的关系。** Proposal 写的是"框不生成逐体素全阳性或框外阴性"，以及"无框的扫描或组织记 annotation_unknown，不作目标阴性"。2026-11-10 的目标修订把"框外为负"定为训练规则（设计文档 §5.2，研究者当天确认）：模型模仿医生的标注，医生没标的地方模型也不标；它只用于训练，不构成"正常"的结论。所以这是一处**有记录的、有意的偏离**，不是实现缺陷。

**归类。**

- "框外为负"：**监督假设**。它假设医生没有画框的地方没有该类别 2 级以上的病变，或者至少这样的地方少到不影响训练。
- 这个假设在负项取"最难的若干比例"时更要紧。被选中的是框外响应最高的体素；如果框外有没有标注的病变，而模型又认得出病变，被选中的恰好就是它们。负项取全部平均时，这类体素被大量容易的负体素摊薄；取前 1% 或 5% 时，它们被集中惩罚。这是从目标的定义直接推出的，不需要实验。
- "框外确实有没有标注的病变，而且多到造成影响"：**待检验的假设**。现有数据答不了：没有体素级的真值，也没有专家复核（阻塞项 `BLOCKED_EXPERT_REVIEW` 仍在）。排序审计只能给出间接的线索：框外宿主组织上概率最高的那一部分体素有多集中、落在哪些扫描上（预注册 §4.2、§4.3）。

## 5. 负监督的来源

**已知的整卷量级（train，86 次扫描，来自已入库的只评价报告）。**

| 项 | 软骨病变 | 半月板撕裂 |
| --- | --- | --- |
| 所有框之外的宿主组织体素（该类别负监督中在宿主组织上的部分） | 17748517 | 4144623 |
| 占全部体素的比例（按每次扫描约 4190 万体素粗算） | 约 0.5% | 约 0.1% |
| 有 / 没有该类主分析框的扫描 | 37 / 49 | 26 / 60 |

- 也就是说，按整卷算，一个类别的负体素里 99% 以上不在它的宿主组织上。
- 训练批次里的比例会高一些：一半的裁块中心取在分割前景或袋上。**具体是多少没有测过**。
- 负项取前 1% 或 5% 时，被选中的体素有多少在宿主组织上，取决于权重；训练日志只记了被选中的比例（每段都是 0.01 或 0.05）和两个平均值，没有记它们的位置。**没有测过**。

**由哪项测量回答。**

- `census`（不需要模型）：训练批次里每个类别的可用负体素，按宿主组织 / 其他已分割组织 / 没有分割标注的体素，再按扫描的三个分组（有该类主分析框 / 只有其他的框 / 没有任何框）拆分。
- 排序审计的分区统计：每个检查点上，概率最高的 0.1% 与 1% 体素落在哪些区。这近似回答"难负样本在哪里"。

**归类。**

- "负监督绝大部分不在宿主组织上"：整卷量级是事实；批次里的构成待测。
- "负项的取法决定了输出的形态"：**证据支持的解释**（中到强）。三次运行只差负项的取法，输出在"大片阳性区"与"零碎响应"之间变化（§3.1）。
- "负项被容易的负体素摊薄，是大片阳性区的原因；按解剖分层取负样本就能修好"：**待检验的假设**。1% 与 5% 两次试验说明"只取难的"这一个旋钮不够，但没有检验"按组织分层"。

## 6. 逐体素的目标与框级输出

**代码事实。**

| 环节 | 训练 | 推理与评价 |
| --- | --- | --- |
| 输入 | 192×192×48 的裁块，一个批次两块，一半以前景为中心 | 整卷滑窗（同样的窗口，步长一半），概率恢复到原始网格 |
| 输出 | 每个体素每个类别一个 logit | 概率 ≥ 0.5 → 连通块 → 不少于 50 体素的保留为所见 → 定位点 → 所在组织 |
| 判断对错 | 袋内最高 10% 的 logit 要高；负体素的 logit 要低 | 所见的定位点落在同类主分析框内算命中 |

目标函数里没有任何一项涉及连通块、所见的个数、大小、形状或中心。命中与否取决于定位点，定位点由**整个连通块的形状**决定；目标对连通块的形状没有约束，只通过"框外为负"间接影响它。

**已有的证据。**

- 原运行：全部主分析框内都有达到阈值的响应，也都被通过体素数过滤的连通块触及；82/106（train）与 42/53（dev）丢在"定位点在框外"。触及框的最大连通块体素数中位数约 3.5 万，只有约二十分之一在框内。
- 1% 试验：框内的响应没有形成 50 体素以上的连通块，所见为 0。
- 两种失败都发生在"概率 → 框级输出"这一段，方向相反。

**归类。** **监督假设**：逐体素的弱监督加上固定的后处理，会给出框级的定位。两者不一致是代码事实。它是不是主要的失败原因，取决于排序审计：

- 概率里有与框相关的排序，命中却不高于对照 → 问题在这一段，值得改目标或改输出形式；
- 概率里没有这样的排序 → 这一段不是瓶颈，先看监督与标注。

另一处不一致：训练时有一半裁块以前景为中心，推理时覆盖整卷，包括训练中较少见到的区域；负项的"最难的若干比例"在两块裁块里合并取，推理时的阳性体素是逐次扫描算的。这两点的影响没有测过。

## 7. 解剖先验

**已有的证据。**

- 换位对照（同一次扫描内沿宿主组织挪动框）下，四次评价的框命中都不高于偶然：5% 第 6000 步、原运行第 6000 步、原运行第 30000 步，以及 1%（没有所见）。**所以目前没有"高于对照的定位"需要用先验去解释。**
- 响应跟着解剖走，而不是跟着标注走，证据强（原运行与 5%）：每一次扫描都有大片阳性区，有没有框都一样；train 上 18 次没有任何框、训练时全部为负的扫描也是如此；不少于 1 万体素的软骨病变所见全部落在股骨软骨上。
- 按达到阈值的体素比例，宿主组织上框内只比框外略高：原运行约 1.1–1.2 倍，5% 约 1.2–1.4 倍，1% 约 1.4–2.1 倍。这是体素比例的描述，没有经过对照检验。
- 跨患者配对给出过很小的 p 值（约 0.001–0.013）。它不是有效的零假设：一个只跟着解剖走的模型也会显著高于它。这些数值不用来主张定位。

**对照的边界。** 换位对照与排序审计的可比摆放都以"这次扫描、这块组织"为条件，所以排除了"只是认得组织"这一种解释。它们排除不了"认得组织内病变常见的那一带"：病变在组织上的分布不均匀时，一个只有位置先验的模型也会高于这个对照。

**归类。**

- "大片响应跟着解剖走"：**证据支持的解释**（强）。
- "模型只有位置先验，没有读病变的影像证据"：**待检验的假设**。只有在排序审计显示"有排序"之后，这个问题才需要回答；那时需要只用解剖位置的对照（`modeling_options_20261114.md` §5）。

## 8. 小结：三类分开

**实现缺陷：** 没有发现。

**监督假设（代码照规定做了，规定里含有的假设）：**

1. 袋内最高 10% 的体素有响应，就等于"框里有病变被找到"；不约束其余体素，不约束空间形态。
2. 袋被裁块切开时，裁块内的部分仍然含有病变。
3. 医生没有画主分析框的地方，没有该类别的病变（"框外为负"）；没有框的扫描整个为负。这一条偏离了 Proposal 的写法，是 2026-11-10 有记录的设计决定。
4. 所有负体素（宿主组织、其他组织、背景）作为同一类负样本处理，按体素等权或按批次内的响应排序。
5. 逐体素的目标加上固定的后处理（阈值、连通块、定位点）会给出框级的定位。

**证据支持的解释：**

- 负项的取法决定输出的形态（三次运行，中到强）。
- 原运行与 5% 的大片响应跟着解剖走，与标注基本无关（强）。
- 正项被三种不同的输出同样满足（代码事实加三次运行）。

**待检验的假设（现有证据不足）：**

| 假设 | 由什么检验 |
| --- | --- |
| 概率里有（或没有）与框相关的排序 | 排序审计（已实现，等批准运行） |
| 负项被非宿主的容易负体素摊薄 | `census` 给出构成；是否是原因需要对照训练 |
| 框外有没有标注的病变，并且被负项惩罚 | 现有数据答不了；需要专家复核或体素级标注 |
| 空间约束能把响应收拢到病变上 | 对照训练（只改正项） |
| 模型只有位置先验 | 只用解剖位置的对照 |
| 106 个框是否足以学到病变特征 | 冻结编码器上的线性探针，或对照训练 |
| 袋被裁块切开造成的标签噪声有多大 | 现有数据答不了病变在袋内的位置；可以比较完整出场与不完整出场时的正项 |
