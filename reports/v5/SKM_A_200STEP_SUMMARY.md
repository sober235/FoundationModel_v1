# v5.1 项目进展与 SKM-A 200 步试训总结

## 结论

v5.1 增量软件实现已完成验收，并已完成一次通过正式 `G-BASE-A` 登记入口的真实 SKM-A GPU 试训：**200/200 次实际参数更新**，仅优化官方训练集的 86 个病例。

官方开发集 33 例用于本轮数据绑定核验，没有参与优化；官方测试集 36 例的影像及标签数组未读取、未评估。**本轮尚无开发集分割指标，也不建立泛化或临床能力结论。**

## 项目进展

软件已接通 v5.1 契约、资格掩码、固定参照评价、原生二维专家 I/O、模块与联合模型、双模式训练、H1/H2/H3 运行接口、受控锁定评分及证据输出。

为本次实际训练补充了受登记配置约束的三维 A-only patch 支持，裁剪同步处理影像、目标、资格和有效 FOV，并将配置纳入登记、协议及 checkpoint 绑定。

| 验证 | 结果 |
| --- | --- |
| 新增 patch 回归 | 18 项先失败、实现后通过 |
| 完整 CPU 回归 | 1725 passed / 2 skipped |
| 跳过项 | 两项需显式启用的 CUDA 测试；本次真实 GPU 试训另外验证 |
| 既有警告 | 16 项固定 vendor 源码的 SciPy 弃用警告 |
| 增量代码、准入材料及最终制品独立审查 | 最终无未解决的可执行问题 |

## 数据划分与标签绑定

旧登记的 `split` 字段虽为 `unassigned`，但 `provenance.release_split` 保留了官方划分。核对数据自带元数据后，确认 155 个病例对应 155 个患者，分区无患者交叉。

| 官方分区 | 数量 | 本轮用途 |
| --- | --- | --- |
| train | 86 | 绑定核验及训练 |
| val | 33 | 绑定核验，不参与优化 |
| test | 36 | 不读取影像/标签数组，不评估 |

对获准的 119 例逐一核对 H5 两路回波、声明的 NIfTI A 标注及 H5 内部六类 `seg`，记录完整资产 hash：

- 107 例交换 X/Y 后，六类标签逐体素完全一致。
- 12 例在固定 X/Y 变换下初次失败；随后核对仓库已有六种固定索引约定，均只有“交换 X/Y 并反转 Z”能使六类全部零误差。原失败证据和逐例变换均保留。
- 没有拟合连续变换、重采样或修改原始标签；**索引一致不等于毫米几何已验证**，物理几何继续保留 unknown。

完整 405 条身份元数据、旧曝光历史及此前单病例诊断的训练曝光均保留。此次队列类型为 `internal`，全部 `strict_locked_eligible=false`；官方 test 分区没有被自动认证为新的独立盲测池。

## 正式登记与固定训练配置

本轮用户已明确确认数据读取及 200 步操作范围。登记材料如实记录该操作批准，不冒称临床专家或机构签名，也不扩展为临床能力或解封批准。

`G-BASE-A` 登记返回 **PASS，阻塞项为空**。实际读取白名单拒绝全部 36 例官方 test 的影像及 A 标注路径，训练器仅选择 `train` 记录。

| 配置 | 固定值 |
| --- | --- |
| 模型 | 三维 baseline，A-only，双输入，六类加背景，width=8 |
| 优化 | AdamW，FP32，学习率 0.001 |
| 初始化种子 | 20261106，随机初始化 |
| 输入处理 | 完整体积归一化后裁剪，不重新做 patch 局部归一化 |
| patch | 32 × 128 × 128 |
| 采样 | deterministic_uniform，seed=17；每病例每 seed 固定同一 crop |
| 预算 | 200 步，最长 7200 秒，每 50 步保存 checkpoint |
| GPU | 单张空闲 A800 80GB，运行进程仅可见所分配 GPU |

## 实际结果与证据

训练正常到达 `MAX_STEPS`，200 条步骤记录均为有限损失、非零监督支持且实际完成优化。86 个训练病例均已消费，其中 28 例访问 3 次、58 例访问 2 次；优化角色只有 `train`。

| 结果 | 实测值 |
| --- | --- |
| 实际优化步数 | 200 / 200 |
| 首步 → 末步训练 loss | 2.9382672310 → 1.0115894079 |
| 前 20 / 后 20 步平均训练 loss | 1.9600844681 / 1.0525810063 |
| 相同固定 crop 首轮 / 次轮平均 loss，86 例 | 1.4140796329 / 1.1056745759 |
| 参数相对初始化的 L1 变化 | 707.2189584412 |
| 运行时间 | 3385.24 秒，约 56.4 分钟 |

完整性及边界检查：

- 第 50、100、150、200 步 checkpoint 均通过配置、架构、采样器及 CUDA RNG 绑定核对。
- 最终 37 组 AdamW 状态均计数到 200，模型及优化器张量均有限。
- 完成后的 checkpoint 经正式入口恢复加载，参数及恢复状态一致，**新增优化步为 0**，原 checkpoint 未改变；这不等于进行了不中断训练的等价性试验。
- 600 条训练访问事件均属于 train 影像/A 标注白名单。
- 训练后重核 238 个获准 train/dev 资产的完整 hash，变化为 0，test 资产读取为 0。
- 模型、逐例记录、源文件定位、访问日志及批准材料保存在私有存储，目录 700、文件 600。

## 限制与当前问题

固定 crop 中 46/86 例含前景，六类均有正例，但前景体素约占 1.77%。因此训练 loss 的下降不能替代逐组织 Dice、完整体积评价或泛化能力验证；重复访问也不增加独立患者支持量。

单批 CPU 准备实测约 17.15 秒，主要耗时在 H5 读取、完整体积归一化及目标/资格构造，指纹核验约占 1.06 秒。当前 pipeline 的主要吞吐瓶颈是 CPU 数据准备。运行期间没有修改已绑定的源码或配置。
