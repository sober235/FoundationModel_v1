# FM_data 同例标签只读核查（amax，2026-11-07）

- **目的：** 研究者决定前期不引入医生，只用 FM_data 及其原有标注。本核查找出同一病例同时有解剖 A 和异常标注（U/S/R）的数据集。按研究者要求，不要求体素级。
- **方法：** 在 amax 上只读：
  - 读数据集自带的元数据和标注文件；
  - 统计标注取值与计数；
  - 抽样核对框、分级与分割 mask 的空间或编号对应。
  - 没有写服务器、复制医学数组，也没有读旧派生目录。
- **范围：** 本文只记计数和标签编码，不含病例 ID 或路径。
- **不是 G-DATA 批准**，也不是全库重认证或标签质量审查。各数据集的使用仍需按来源与版本批准。
- 这里的“框级/组织级”不是体素级参照，不能据此记为体素级联合完成（Proposal §0.5、§5.0）。

## 结论

| 数据集 | 同例 A | 异常标注 | 可用粒度 | 前期联合场景 |
|---|---|---|---|---|
| SKM-TEA | 6 类人工分割 | 3D 框（16 类、4 大类）+ 每框 `tissue_id` | A 体素级；U 框级；R 组织级；S 只有阳性 | **主场景**（研究者 2026-11-07 批准） |
| SPIDER | 椎体、椎管、椎间盘分割（半自动后人工修正） | 每椎间盘的放射学分级 | A 体素级；S 组织级（阳性与阴性均显式）；R 为分级所挂的椎间盘；无 U 范围 | **第二场景**（同上） |
| UCSF-PDGM | 只有全脑/脑实质二值 mask（全脑 mask 来自深度学习去颅骨） | 肿瘤分割，取值 1/2/4 | 体素 U；无解剖分区 A | 否 |
| SibBMS | 无 | 病灶标注仅 10 份，取值 1/2/3 | — | 否 |
| fastMRI（含附加框） | 无解剖分割 | 二维框，标签带组织名 | — | 否 |
| ISLES-2022、UCSF-BMSR | 无 | 病灶分割 | 只有 U | 否 |
| AMOS、TotalSegmentator MRI | 有 | 元数据无病理字段 | 只有 A | 否 |

FM_data 中没有同例的体素级 A + 体素级 U。两个合格场景各缺一项：

- SKM-TEA 没有已确认的阴性；
- SPIDER 没有异常范围 U。

两者是不同病例、不同部位，不能相加为同例联合结果（Proposal §1.3）。

## SKM-TEA

- 155 次扫描、155 名受试者，每人一个时间点。官方划分 86/33/36。
- **分割：** 每次扫描 512×512×160×6，布尔型，人工分割。通道依次为：
  1. 髌骨软骨
  2. 股骨软骨
  3. 胫骨软骨内侧
  4. 胫骨软骨外侧
  5. 内侧半月板
  6. 外侧半月板
- **框：** 476 个 3D 框，依据放射学报告人工标注。各划分 242/104/130。
  - 每框字段：类别、`tissue_id`、`bbox`、`confidence`（0–5）、`labeler`（1/2）。
  - `labeler`：1 号 193 个，2 号 283 个。
  - `confidence` 分布：

    | 0 | 1 | 2 | 3 | 4 | 5 |
    |---|---|---|---|---|---|
    | 6 | 5 | 52 | 203 | 150 | 60 |

- **`tissue_id` 编码：** 1 半月板，2 ACL，3 PCL，4 股骨软骨，5 髌骨软骨，6 胫骨软骨，−1 无组织（积液）。
- **大类 × 组织计数：**

  | 大类 | 组织 | 框数 | 说明 |
  |---|---|---|---|
  | 软骨病变 | 股骨软骨 | 112 | |
  | 软骨病变 | 髌骨软骨 | 56 | |
  | 软骨病变 | 胫骨软骨 | 43 | |
  | 半月板撕裂 | 半月板 | 107 | |
  | 韧带撕裂 | ACL | 30 | ACL 无分割 |
  | 韧带撕裂 | PCL | 9 | PCL 无分割 |
  | 积液 | −1 | 117 | 不归属组织 |
  | 韧带撕裂 | 半月板 | 1 | 类别与组织不符 |
  | 软骨病变 | ACL | 1 | 类别与组织不符 |

  组织在现有分割内、且类别一致的框共 318 个。与分割通道的对应：半月板 ↔ 内侧 + 外侧半月板；胫骨软骨 ↔ 内侧 + 外侧。
- **坐标：** `bbox` 为 `[X, Y, Z, dX, dY, dZ]`，轴序与分割数组相同（SI、AP、LR）。
  - 抽样 29 个带组织的框：29/29 与其 `tissue_id` 对应的分割有重叠。
  - 其他五种轴序最多 12/29。
- **`inspected`：** 数据集文档的定义是“至少一名标注者看过”。
  - 145 次扫描为 True，10 次为 False。
  - 无框扫描 25 次，其中 15 次已 inspected，10 次未 inspected。
  - 无框不等于已确认阴性，只能记为“报告未记载”。
- **已知限制：** 官方测试划分在历史运行中可能已曝光，以 T08 曝光账本为准。

## SPIDER

- 218 名患者、447 个序列：t1 196，t2 210，t2_SPACE 41。
- **分割：** MHA 格式。取值 1..N 为椎体，100 为椎管，201..20N 为椎间盘。据数据集文档，先半自动生成，再人工修正。
- **分级表：** 1520 行，按患者与椎间盘编号记录，不含序列字段。
  - 椎间盘编号 k 对应分割取值 200+k：抽样 6/6 吻合。
  - 2 行编号为 0，无对应分割。
  - 218 名患者都有分级，也都有分割。
- **分级项与计数：**

  | 分级项 | 取值:行数 |
  |---|---|
  | Modic | 0:1006, 1:4, 2:503, 3:7 |
  | 上终板 | 0:906, 1:614 |
  | 下终板 | 0:897, 1:623 |
  | 滑脱 | 0:1478, 1:42 |
  | 椎间盘突出 | 0:1448, 1:72 |
  | 椎间隙狭窄 | 0:976, 1:544 |
  | 椎间盘膨出 | 0:774, 1:746 |
  | Pfirrmann | 1:286, 2:341, 3:418, 4:291, 5:184 |

- **使用时须写明的三点：**
  - 可读来源未写明分级者。来源记为“数据集发布，分级者未注明”。
  - 分级按患者给出，不对应具体序列。所以 `annotation_modalities` 与输入可见性按 Proposal §2.3 记为 unknown。
  - 终板与 Modic 分级挂在椎间盘编号下，实际位于相邻椎体终板。用作 R 时，须在 scope 中写明归属语义。
- 哪些分级算“目标异常”（例如 Pfirrmann 的阈值）是临床定义，由研究者在冻结 scope 前写定。Agent 不填（plan Global Constraint 7）。
