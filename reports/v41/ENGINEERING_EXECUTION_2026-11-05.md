## 2. 执行范围

本轮实现以执行时的 v4.1 `spec.md` 为唯一规格依据，覆盖数据治理、监督资格、A/U/R 模型与评价、H1/H2/H3 开发实验、外部扩展校验及解封证据流程。

- **A**：解剖结构。
- **U**：目标异常范围。
- **R_geo**：依据已定义规则计算的几何关系。
- **R_clin**：需要独立专家语义参照的临床关系。

几何关系不能替代临床关系，框或伪标签不能替代合格像素参照，不同数据集上分别取得的结果不能相加冒充同例联合能力。

## 6. 关键决策与兼容性代价

| 决策 | 理由与后续代价 |
| --- | --- |
| 版本字段、隔离 split 和闭合 provenance 契约保持一致 | 防止生产记录与 schema 分离；后续修改需同步消费者和回归测试 |
| 旧 `bbox` 仅在新版本副本迁移 | 不放宽资格规则，不覆盖原始数据；后续使用必须明确版本与哈希 |
| 空分母返回 `None`，患者作为独立单位 | 不制造有效样本或成功率；消费者须处理未定义结果 |
| 发布排他且不可覆盖，使用 Linux 无覆盖重命名 | 防止并发覆盖；其他平台需提供等效安全适配 |
| 白名单显式解析绝对路径并保留所有角色的冲突否决 | 避免隐式授权；调用方需承担规范化和受控访问责任 |
| 未知几何明确保留未知状态 | 防止伪造物理指标；相关临床导出或物理评价需补足可靠几何 |
| A 背景监督须满足全部前景类别的合格性 | 不把未复核类别变成背景；资格较少时监督支持相应减少 |
| 数值范围观察不等于语义批准 | P1 未登记语义不能转为真值；需要后续明确来源与本体政策 |
| 训练只优化 train，预算跨恢复段累计 | 可读 development 不代表可优化；续跑不能静默重置预算 |
| CPU 随机数与所分配 GPU 随机数隔离 | 避免触碰未分配设备；新增构建器必须遵守同一规则 |
| H1 主 FP 比较要求显式冻结目标类别范围 | 遗漏的类别不能从提交行中消失；缺少范围须阻塞，旧摘要需重新评价 |
| H2 上界必须使用同影像队列的合格训练参照 | 防止不同数据或隐藏信息造成不公平比较；不满足来源绑定时拒绝运行 |
| CAP 与图像对照保持真实参数匹配 | 不以无效参数填充匹配；新增对照须验证实际信息边界 |
| 实例、类别、FOV 与候选哈希一起绑定 | 不允许窗口身份混合或无效区域产生关系；改变策略须重新登记 |
| 二维使用单切片实际输入，保留选定的外部归一化 | 不读取邻层、体积统计或缓存；旧归一化语义 checkpoint 不能直接重标 |
| 六项模式覆盖分别报告 | 2D/3D × A/U/R 独立验收；三维成绩不能补二维缺项，框不能验收像素分割 |
| 外部独立性与临床参照覆盖分开 | 未知谱系或组级调参污染不能冒充盲测；角色只发布汇总，不发布身份列表 |
| 临床参照允许合格独立专家的 study/instance 判断 | 不强制临床语义成为体素掩膜；仍须绑定实际注释与范围，排除 pseudo-only/excluded |
| READY 采用无循环的先前科学协议与实际门槛文件链 | 科学字段和运行输入必须一致；文件变更或签核不匹配需新批准版本 |
| 本体文件字节及实际消费缓存都受冻结约束 | 配置不属于源码摘要时仍不能漂移；缺失绑定或旧缓存不能静默修补 |
| 解封占用后永久消耗授权 | 崩溃或评分失败也不得重置；恢复需新批准协议并披露曝光和偏离 |
| 执行证据保留受限归档，入库仅发布整理后的总结 | 保留恢复能力，同时不把私有路径、逐例数据或原始审计键公开 |

旧 H1 v1 摘要须基于显式目标范围和真实合格参照重新生成 v2，不能只修改版本号。旧双模式归一化语义或缺少本体绑定的协议也不能通过补填元数据冒充新登记版本。

## 7. 锁定运行的支持范围

| 能力 | 当前边界 |
| --- | --- |
| A/U 锁定评分 | 可信内建模型的 CPU 绝对端点、明确冻结的 mean-Dice 决策与参照覆盖 |
| R_geo 锁定评分 | 三维、单 U 类别、独立合格同例人工 A/U、固定实例及关系政策、joint 与 FP 约束 |
| 临床 R 锁定评分 | 不支持；需要独立临床语义参照加载器与相应评价实现 |
| 二维或多 U 类别锁定 R | 不支持；不能用三维物理关系结果替代 |
| H1/H2/H3 比较性锁定 driver | 尚未接入；已有开发比较接口不等于锁定比较已实现 |
| 完整六模式及项目成功 | 缺少必要模式、比较或证书证据时不能声明完成 |

解封前需验证冻结协议、模型与 checkpoint、完整记录、源码、本体、READY 证据及授权。先持久化排他占用，再发布新的 `used: true` 批准版本，随后才读取受保护影像和参照；原批准文件不覆盖。

证书、逐例结果与访问日志保持私有。公共输出只包含受控状态、数量、覆盖率和数值汇总。其安全边界依赖可信私有存储和调用方，未声称能抵御任意操作系统或存储层攻击。
